The website was developed on a local Open Panel Server. 
To run it, you need to download this server, and then create a folder for this site in the home folder. 
Name: praktika.local (you can name it in your own way, but for this you will need to edit the data in the project.ini file). 
After that, you need to create a folder.osp and move the project.ini file there, and all other files to a folder called public (which also needs to be created)
